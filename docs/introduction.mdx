# Welcome to Diet Food Delivery

Diet Food Delivery is a modern food delivery application built with React and Vite, featuring real-time order management, user authentication via Firebase, and comprehensive admin controls.

## Key Features

- **User Authentication**: Secure login with Firebase
- **Order Management**: Real-time order tracking and updates
- **Drag-and-Drop Interface**: Intuitive UI for order management
- **Admin Dashboard**: Complete control over restaurants, menus, and orders
- **Responsive Design**: Works seamlessly on desktop and mobile

## Technology Stack

This application is built with:
- **Frontend**: React 19 + Vite
- **Backend**: Node.js/Express
- **Database**: Firebase Realtime Database
- **Styling**: CSS with responsive design
